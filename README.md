# Prompt Library

A collection of prompts for setting up AI agents that run themselves —
daily plans that update based on your feedback, no code required.

Each one is a copy-paste prompt for an AI assistant with access to your
own tools (Notion, a scheduler, etc.). Pick the one you want, paste it in,
and follow the setup notes.

## Prompts

- **[AI Workout Agent](./prompts/ai-workout-agent.md)** — a self-updating workout
  tracker: a daily plan that adjusts based on what you actually did and
  what you tell it. The structure generalizes easily to meal planning, a
  study schedule, a content calendar, or anything else you want to run on
  autopilot.

More prompts will be added here over time.
